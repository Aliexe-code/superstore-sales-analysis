# GitHub Issues + Milestones for Day-by-Day Management

Open-ended 4-day work benefits from visible milestones. We decided to manage Days 16-18 via 8 GitHub Issues grouped into Milestones (Day 16, Day 17, Day 18), each Issue with a clear Definition of Done linked to the 36-item checklist. This is more visible and rewarding than a static markdown checklist.

Considered Options: Shared todo.md; verbal daily check-ins only; Trello board outside GitHub.
Consequences: Issues are created once and closed as commits are pushed. Progress is visible in the repo itself without external tools. Requires one-time Issue creation (provided as `docs/task-board.md`).
