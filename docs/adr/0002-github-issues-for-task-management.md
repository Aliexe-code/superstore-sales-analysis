# GitHub Issues + Milestones for Day-by-Day Management

Eman is distracted and confused by open-ended work. We decided to manage the remaining Days 16-18 via 8 GitHub Issues grouped into Milestones (Day 16, Day 17, Day 18), each Issue with a clear Definition of Done linked to the 36-item checklist. This is more visible and rewarding than a static markdown checklist.

Considered Options: Shared todo.md; verbal daily check-ins only; Trello board outside GitHub.
Consequences: Mentor creates Issues once, assigns to Eman; Eman closes Issues as she pushes commits. Progress is visible in the repo itself without external tools. Requires mentor to do one-time Issue creation (provided as `docs/task-board.md`).
